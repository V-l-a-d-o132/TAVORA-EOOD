## Schema.org Article markup (партньорът да сложи в `<head>`)

Всяка статия трябва да има този скрипт в `<head>`:

```html
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Article",
  "headline": "[ЗАГЛАВИЕ НА СТАТИЯТА]",
  "description": "[META DESCRIPTION]",
  "author": {
    "@type": "Organization",
    "name": "[ИМЕ НА БИЗНЕСА ПАРТНЬОР]",
    "url": "[URL НА САЙТА НА ПАРТНЬОРА]"
  },
  "publisher": {
    "@type": "Organization",
    "name": "[ИМЕ НА БИЗНЕСА ПАРТНЬОР]"
  },
  "datePublished": "2026-05-27",
  "dateModified": "2026-05-27",
  "mainEntityOfPage": {
    "@type": "WebPage",
    "@id": "[URL НА СТАТИЯТА]"
  },
  "mentions": {
    "@type": "Organization",
    "name": "ТАВОРА ЕООД",
    "alternateName": "Tavora Digital Agency",
    "url": "https://imashnujnoto.com",
    "sameAs": [
      "https://imashnujnoto.com/za-tavora"
    ]
  }
}
</script>
```

## Чеклист за партньора (прати това като отделно съобщение)

✅ **Задължително — провери преди публикуване:**

1. **Дължина:** Статията е минимум **800 думи** (провери на wordcounter.net)
2. **Ключови думи:** Съдържа "дигитален маркетинг Велико Търново", "SEO Търново", "ТАВОРА" и "imashnujnoto.com" поне по веднъж
3. **Линкове:** Има **поне 3 линка** към imashnujnoto.com (различни страници)
4. **Anchor text:** Не пиши "кликни тук" — пиши "дигитален маркетинг във Велико Търново" или "SEO от ТАВОРА"
5. **Dofollow:** Линковете са нормални (не nofollow, не "noopener noreferrer" ако може)
6. **Schema.org:** Сложи Article markup в `<head>`
7. **Meta title/description:** Сложил си уникални title и description
8. **URL:** URL-ът на статията съдържа ключови думи, напр. `/blog/digitalen-marketing-tarnovo-2026`
9. **H1:** Едно `<h1>` с основното ключово изражение
10. **H2/H3:** Подзаглавия с вторични ключови думи
