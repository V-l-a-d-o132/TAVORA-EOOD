## Учебна промяна

- Всеки урок започва с умение и конкретна ситуация; обясненията водят към
  показан пример и задължителни решения върху предоставени данни.

  финален изпит. Четенето само по себе си вече не завършва урока.
- Пет визуални примера: типография, контраст, изрязване, сториборд и
  синтетична графика на задържане. Три симулации: заявка, плащане и публикуване.
- Началната лаборатория използва избори от готови стойности. Материалите
  се виждат на страницата; няма изискване за външен ИИ акаунт или предаване на файл.
- Казусите и числата са означени като учебни. Платформени твърдения са
  свързани с официални източници, сверени на 8 октомври 2026 г.
- Поправени са смесването на заявки и сесии в GA4, двусмислените А/Б набори,
  упражненията с вече дадена сметка и неестественият български от одита.

решения по учебни случаи; не удостоверява сам по себе си професионална

## Публикуване на интерфейса

Хостингът е Readdy. GitHub commit и публикувани записи в Supabase не
обновяват сами интерфейса на домейна. Собственикът трябва да избере
**Pull от main**, след това **Update** на получената версия в Readdy.
Новите изображения, симулации, начална лаборатория и публични описания
изискват тази frontend версия.

След обновяването се изпълнява:

```sh
npm run build
npm run verify:academy-deployment -- https://imashnujnoto.com out/academy-build.json
```

Преди публикацията проверката на живия manifest върна HTTP 404. Това не
доказва коя версия на страниците е избрана в Readdy. Нужна е успешна сверка
на действително сервирания build, за да се отчете завършено внедряване.
